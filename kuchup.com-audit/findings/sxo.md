# SXO (Search Experience) — kuchup.com

**Score: 58 / 100**

## Primary intents tested

1. `visa sponsored software jobs Europe relocation`  
2. `visa sponsorship software jobs Germany`

## SERP consensus (observed)

Dominant winners are **long-form visa guides** and **specialized job boards / country job indexes** (e.g. Euro Top Tech style guides, Next Level Jobs country pages, sponsorship hubs). Features: Blue Card thresholds, sponsor company lists, process steps, and links into live roles.

**Dominant page type:** Hybrid **Guide + Jobs index** (confidence ~70%).

## User stories (from SERP signals)

1. **Awareness:** “As a non-EU engineer, I need to know which countries’ visas I can actually get.” → SERP rewards threshold tables; homepage defers to product.  
2. **Consideration:** “As a seeker, I want companies that historically sponsor, not generic LinkedIn noise.” → Competitors list sponsors; Kuchup should surface sponsorship signals in-board.  
3. **Decision:** “As a user ready to apply, I want a tracked pipeline + CV tailoring.” → Strong unique wedge (MCP) — keep, but don’t lead SEO for head terms with only this.

## High recommendations

1. For country URLs: lead with **visa snapshot + live role count + sample jobs**, then FAQ.  
2. For homepage SEO: either (a) add a visible “Europe sponsorship snapshot” section matching SERP guide expectations, or (b) make country hubs the SEO landing targets and keep `/` brand/product.  
3. Capture brand SERP for “Kuchup” / “Relocation Jobs” with consistent naming.

## Falsifiability

- Mismatch remains if country pages still lack live jobs/counts above the fold.  
- SXO improved if top queries start showing country URLs with CTR > site average in GSC (post-key setup).
